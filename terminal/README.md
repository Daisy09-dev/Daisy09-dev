# DAISY09 Cyberpunk Terminal

A macOS Terminal animation featuring:

- Full-screen neon-blue Chinese character rain
- A rotating capybara made from Chinese typography
- Automatic terminal-size detection
- A seven-second animated sequence

## Run

```bash
python3 fullscreen.py
```

## Loop continuously

```bash
while true; do python3 fullscreen.py; done
```

Stop with Control+C.

Requires Python 3 and a Unicode-capable terminal.
